# **Acme Shopping Cart Platform**
### Modern, seamless online shopping experience  
#### Executive Overview

---

# **Vision**
Deliver a premium, frictionless ecommerce experience  
that reflects the quality of Acme’s products.

- Simple, intuitive browsing  
- Elegant, mobile-ready design  
- Secure checkout  
- Clear order visibility  
- Strong customer identity foundation  

---

# **Business Goals**

### **Drive Revenue**
Enable frictionless digital purchasing for high-demand products.

### **Improve Customer Experience**
Fast, intuitive UI with minimal barriers to purchase.

### **Reduce Support Load**
Customers can view profile + order history themselves.

### **Future Expansion**
Foundation for payments, promotions, subscriptions, and mobile apps.

---

# **The Customer Experience**

### **1. Browse Catalog (No Login Required)**
- Paginated product listing  
- High-quality images  
- Real-time search and sort  

### **2. Product Detail**
- Pricing  
- Image  
- Description  
- Add to cart  

---

# **The Shopping Cart**

### Seamless Cart Management
- Add, remove, change quantity  
- Cart persists through the session  
- Clean, high-end UI for premium products  

---

# **Authentication (Only at Checkout)**

### Why this matters:
- Keeps browsing friction-free  
- Reduces drop-off  
- Streamlines identity handling

### Powered by:
- Acme Identity Server  
- OpenID Connect  
- Secure access token handling  

---

# **Checkout Experience**

### Seamless, Secure, Guided
- Fast login via IdentityServer  
- Single shipping/contact address  
- Order created through ShoppingCart API  
- No payment required yet (future phase)  

---

# **Customer Profile**

### Self-Service Features
- View / update name, email, birthdate  
- Profile tied to identity through OIDC “sub” claim  
- Clean form UI  

---

# **Order History**

### Full Visibility for the Customer
- List of all past orders  
- Order detail page  
- Itemized list with price + status  
- Reduces support inquiries  

---

# **Key Advantages**

### **For Customers**
- Premium user experience  
- Clear communication  
- Secure profile and order access  

### **For Acme**
- Consistent identity  
- Reliable order tracking  
- Future-proof platform

# **Platform Overview**
- React + TypeScript + Tailwind  
- SPA architecture  
- Catalog API for items  
- ShoppingCart API for customer + orders  
- IdentityServer for auth
